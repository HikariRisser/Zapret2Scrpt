## Zapret2 Windows / Linux 1.8.2

### Как обновиться

- **Linux:** скачайте `zapret2-linux.sh` из вложений и замените им прежний файл.
- **Windows:** скачайте **один** файл — `Zapret2Windows.cmd` или `Zapret2Windows.ps1` — и замените прежний.

Затем в меню туннеля выберите пункт **[6]**.

### Трансляции Discord: проверка и автоматический обход

Трансляции Discord (Go Live) идут через медиасерверы в сети Cloudflare. У части провайдеров UDP к ним обрезается примерно через секунду после начала соединения. Выглядит это так: предпросмотр трансляции виден, но зрители не могут подключиться, а чужие трансляции не открываются. Голос при этом может работать. zapret такое не исправляет: поток режется по адресу, а не по содержимому первых пакетов.

Пункт **[6]** меню туннеля теперь проверяет и это. В итоговом сообщении появилась строка «Трансляции Discord»:

- **«работают через zapret»** — ничего не меняется;
- **«zapret не справляется»** — UDP к медиасерверам Discord (`104.29.0.0/16`) автоматически направляется в туннель, туннель перезапускается. TCP к этим адресам (сайты на Cloudflare) и голосовые серверы на других адресах по-прежнему идут напрямую через zapret. Трансляцию после этого нужно начать заново.

Список доменов туннеля здесь ни при чём: Discord шлёт медиа по адресу, который получает в сигнальном соединении, без DNS.

Вернуть как было: удалить файл `discord-media.on` в каталоге туннеля (Linux — `/opt/zapret2/tunnel/`, Windows — `C:\Windows\System32\Zapret2Windows\tunnel\`) и перезапустить туннель.
