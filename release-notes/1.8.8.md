# 1.8.8

Мелкое улучшение Windows-версии: видимость первичной проверки DNS.
Изменений в Linux нет (версия выровнена для самообновления и единого
релиза).

## Изменено (Windows)

- **Первичная проверка DNS (при первом запуске обхода) больше не тихая.**
  Раньше она вызывалась с подавлением пошагового вывода: пользователь
  видел только итоговую сводку, а что происходит в этот момент (и на чём
  проверка споткнулась) — не видно было вовсе. Теперь проверка идёт в
  обычном режиме: видно список доменов и их разрешение по ходу
  («[3/45] example.com   142.250.185.78»), домены, у которых системный
  DNS в порядке, и домены без рабочего IP. Ошибка проверки, как и раньше,
  останавливает её и печатается полностью.
- Из сообщения убрана оценка времени «до минуты»: она не соответствовала
  действительности на медленных DNS и на больших списках (каждый домен
  может упираться в таймаут).
- Повторное обновление из меню (пункт [7]) и команда `-Action DohHosts`
  работали и работают в этом режиме — изменилось только поведение
  первой проверки.
