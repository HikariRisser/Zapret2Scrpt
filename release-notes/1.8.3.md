## Zapret2 Windows / Linux 1.8.3

### Как обновиться

- **Linux:** скачайте `zapret2-linux.sh` из вложений, замените им прежний файл и перезапустите обход (пункт **[2]** дважды).
- **Windows:** скачайте **один** файл — `Zapret2Windows.cmd` или `Zapret2Windows.ps1`, — замените прежний и перезапустите обход.

### Исправление: зависания видео YouTube

Для доменов из списков работает автоперебор стратегий (`circular`). Если стратегия не срабатывает, соединение повисает, и после двух таких сбоев домен переключается на следующую стратегию. Раньше каждое такое соединение ждало таймаутов TCP. YouTube грузит видео со множества серверов `googlevideo.com`, поэтому, пока подбиралась стратегия (после каждого запуска обхода, а иногда и посреди просмотра), видео надолго зависало.

Теперь соединение, на котором обнаружен сбой, сразу обрывается. Браузер тут же переподключается и получает следующую стратегию, так что вместо долгих зависаний бывают короткие паузы в первые секунды.

Новый пункт главного меню **[12] «Быстрый подбор стратегий (обрыв зависших соединений)»** включает и выключает это поведение. По умолчанию оно включено.

### Прочее

- **Windows:** параметры запуска winws2 теперь пересобираются при каждом запуске обхода. После обновления скрипта больше не нужно выполнять пункт [1], чтобы изменения вступили в силу.
