# 1.8.9

Исправление Windows-версии: отказ записи в hosts больше не срывает
первичную проверку DNS. Изменений в Linux нет (версия выровнена для
самообновления и единого релиза).

## Исправлено (Windows)

- **«Проверка DNS не выполнена: Exception call "WriteAllLines" with "3"
  argument(s): access to the path 'C:\WINDOWS\System32\drivers\etc\hosts'
  is denied».** На чистой системе при первом запуске обхода первичная
  проверка DNS падала с Access denied при перезаписи hosts, хотя скрипт
  работает от администратора, и повторялась при каждом старте. Причины:
  атрибут файла «только чтение» (WriteAllLines падает с этой ошибкой даже
  у администратора) либо защита hosts антивирусом — самозащита файла у
  Kaspersky, Dr.Web, Avast, 360 и др., либо «Контролируемый доступ к
  папкам» Защитника Windows.
- Все записи hosts (обновление DoH-блока, снятие его при удалении,
  удаление туннельных доменов) теперь идут через одну функцию
  Write-HostsFile: она снимает атрибут «только чтение» перед записью, а
  при отказе доступа не падает, а печатает понятное объяснение и
  продолжает работу. Обход работает и без записи в hosts; повторить
  запись можно пунктом меню [7].
- Маркер первичной проверки (lists\doh.done) при отказе записи в hosts
  теперь ставится: заведомо неудачная попытка не повторяется при каждом
  запуске обхода.

## Тесты

- +3 Pester-теста Write-HostsFile: запись и возвращаемое значение,
  снятие атрибута «только чтение», отсутствие BOM при ascii-содержимом.
