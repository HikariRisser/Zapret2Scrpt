# 1.8.6

Хотфикс Windows-версии: добавление своего конфига VPN падало на
русской/украинской Windows. Изменений в Linux нет (версия выровнена для
самообновления и единого релиза).

## Исправлено (Windows)

- **«Administrators: No mapping between account names and security IDs was
  done» при добавлении конфига VPN.** Права на каталог с профилями
  (`tunnel\`) и на боевой каталог выдавались через `icacls` по **именам**
  встроенных групп (`SYSTEM`, `Administrators`, `Users`). Эти имена
  локализованы: на русской Windows группа называется «Администраторы»,
  на украинской — «Адміністратори», и имя `Administrators` не сопоставляется
  ни с одной учётной записью. Теперь учётки задаются **SID-ами**
  (`*S-1-5-18` SYSTEM, `*S-1-5-32-544` Administrators, `*S-1-5-32-545` Users) —
  SID одинаков во всех языковых версиях Windows.
- Импорт профиля больше не прерывается сбоем установки прав: ACL — это
  защита, а не условие работы туннеля (в Linux версия вела себя так же и
  ошибки не выдавала). Сбой ACL теперь сообщается предупреждением, а не
  исключением; добавлен второй проход для старых сборок `icacls`, где
  несколько `/grant:r` в одной команде применяются не полностью (результат
  проверяется перечитыванием ACL).

## Тесты

- 3 новых Pester-теста: `Protect-Directory` выдаёт права через SID
  (`*S-1-5-18`, `*S-1-5-32-544`, `*S-1-5-32-545`) и не использует
  локализуемые имена групп в аргументах `icacls`. Всего 31 тест.
