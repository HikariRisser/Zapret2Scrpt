# 1.8.10

Исправление Windows-версии: 1.8.9 не запускалась из-за ошибки
`unable to find type [IOException]`. Изменений в Linux нет (версия
выровнена для самообновления и единого релиза).

## Исправлено (Windows)

- **`unable to find type [IOException]`** при любом запуске скрипта.
  В 1.8.9 обработчик в Write-HostsFile был объявлен как
  `catch [UnauthorizedAccessException],[IOException]`: короткое имя
  IOException не входит в набор автоматически доступных имён типов
  и не резолвится (в отличие от, например, `Net.WebException`).
  Теперь используются полные имена:
  `catch [System.UnauthorizedAccessException],[System.IO.IOException]`.
- Остальные изменения 1.8.9 остаются в силе: отказ записи в hosts
  (атрибут «только чтение», самозащита hosts антивирусом,
  «Контролируемый доступ к папкам») больше не срывает первичную
  проверку DNS и не повторяется при каждом старте обхода;
  все записи hosts идут через Write-HostsFile; повтор — пункт меню [7].

## Тесты

- Новый Pester-тест-инвариант: **все типы в `catch [...]` должны
  резолвиться** (проверка по всей конструкции, включая второй и
  последующие типы списка). Регрессия 1.8.9 воспроизводится этим тестом.
- Pester-тесты Write-HostsFile (из 1.8.9) проходят.
