## Zapret2 Windows / Linux 1.8.0

### Как обновиться

- **Linux:** скачайте `zapret2-linux.sh` из вложений, замените им прежний файл и перезапустите обход (пункт **[2]**). Запуск: `sh zapret2-linux.sh`.
- **Windows:** скачайте **один** файл — `Zapret2Windows.cmd` (запуск двойным щелчком) или `Zapret2Windows.ps1`. Второй файл рядом больше не нужен. Если автозапуск уже был включён, выключите и снова включите его (пункт **[3]**).

### Что нового с 1.7.1

**Внешний список сайтов с региональными ограничениями (обе системы).** Сайты, которые сами не пускают из России (claude.ai, chatgpt.com, spotify.com и подобные), теперь идут через туннель без ручного добавления:

- при включении туннеля скачивается список GeoBlock проекта [itdoginfo/allow-domains](https://github.com/itdoginfo/allow-domains), около 500 доменов;
- список обновляется раз в сутки и при запуске туннеля, если копия старше суток;
- свой список туннеля не меняется;
- меню туннеля: **[11]** обновить сейчас, **[12]** выключить или включить список.

Весь трафик этих сайтов идёт через сервер туннеля. Если видео или музыка из списка работают медленно, выключите список и добавьте нужные сайты вручную.

**Windows: один файл.** `Zapret2Windows.cmd` содержит весь скрипт и работает без `.ps1`; `Zapret2Windows.ps1` работает без `.cmd`.

**Windows: скорость.**

- Меню больше не задерживается на каждом шаге: состояние определяется без запросов WMI и планировщика.
- Проверка DNS через DoH проверяет все домены одновременно, а не по одному.
- Проверка DNS перенесена с установки на первый запуск обхода.

**Windows: исправления.**

- Меню сразу запрашивает права администратора: раньше выбранный пункт терялся.
- Окно одноразового действия с повышенными правами не закрывается до прочтения результата.
- Обновление среды не включает автозапуск, выключенный вручную.
- Автозапуск срабатывает и при работе ноутбука от батареи.
- Туннель запускается при выключенном IPv6 и настраивается до установки среды.

### Что проверено

- **Linux:** внешний список проверен на подставных данных (разбор, объединение со своим списком, обновление по возрасту, сбой загрузки); настоящий sing-box принимает набор из 1000 доменов. Загрузка списка из сети и суточное обновление таймером не проверялись.
- **Windows:** скрипт после переработки ни разу не запускался и не проверялся разбором PowerShell — возможны ошибки. Проверены только баланс скобок и наличие всех вызываемых функций. Для Windows этот выпуск считайте непроверенным.
