## Zapret2 Windows / Linux 1.8.4

### Как обновиться

- **Linux:** скачайте `zapret2-linux.sh` из вложений и замените им прежний файл.
- **Windows:** скачайте **один** файл — `Zapret2Windows.cmd` или `Zapret2Windows.ps1` — и замените прежний. После обновления один раз выполните установку (пункт **[1]**) или включите автозапуск заново (пункт **[3]**) — задачи планировщика переключатся на защищённую копию скрипта.

### Безопасность

- **Задачи планировщика запускают защищённую копию скрипта** (`C:\Windows\System32\Zapret2Windows\`), а не файл из рабочей папки. Раньше задача от имени SYSTEM выполняла скрипт оттуда, куда его положил пользователь: любую программу пользователя это делало повышением привилегий. Копия синхронизируется при установке, при включении автозапуска и при обновлении скрипта (пункт **[9]**).
- **Скачивания сверяются с SHA-256**: релиз zapret2, sing-box и xray-core сравниваются с контрольными суммами официальных релизов, несовпадение останавливает установку. Версия xray-core закреплена (v26.11.9) вместо `releases/latest`.
- **Явные права на каталоги**: боевому каталогу и каталогу туннеля задаются ACL напрямую (`icacls`) — ключи профилей (`profiles.json`) больше не читаемы обычными пользователями. Пользователям остаётся только чтение боевого каталога.
- Установщик .NET Framework проверяется по подписи Microsoft (Authenticode).
- Служба WinDivert перерегистрируется, только если она указывает на каталоги проекта — чужая служба стороннего приложения не трогается.
- Обновление скрипта: новый файл проверяется синтаксисом ДО записи, файл подменяется атомарно (через временный файл), резервная копия сохраняется как раньше.

### Исправления

- `hosts` при обновлении DNS больше не перезаписывается принудительно в ASCII: файл с кириллическими комментариями сохраняется как есть (UTF-8), а не молча превращается в знаки вопроса.
- Устранена гонка при первой установке: если каталог релиза появился, пока шла загрузка, установка больше не удаляет его молча, а использует или останавливается с понятным сообщением.
- У больших загрузок (релиз, sing-box, xray) появился таймаут; отключён прогресс-бар `Invoke-WebRequest`, замедлявший загрузку в PS 5.1.
- Код выхода внешних программ при проверке конфигов sing-box/xray сбрасывается перед вызовом: отсутствие файла больше не выглядит как успех предыдущей команды.
- Проверка версии PowerShell требует именно 5.1 (раньше пропускала 5.0), pwsh 6/7 предупреждает о непроверенности.
- **DoH (обновление DNS) идёт параллельно и с кэшем**: три провайдера опрашиваются одновременно через `HttpClient`, а не последовательными `Invoke-RestMethod` с таймаутом 6 с каждый — недоступный провайдер больше не растягивает разрешение каждого имени на десятки секунд. Ответы `Resolve-DohName`/`Resolve-DohCname` кэшируются на время работы, так что `www.X → X` и повторные имена не бьют в сеть заново (замер: ~650 мс на имя с тремя провайдерами по 600 мс задержки против ~1800 мс последовательно).

### Мелкие исправления

- Ссылки `ss://` без `@` (повреждённые) дают внятную ошибку вместо необработанного исключения.
- `Test-BogonIP` понимает IPv6-заглушки: `::`, `::1`, `fe80::/10`, `fc00::/7`, `ff00::/8`, а также IPv4-многоадресные и зарезервированные диапазоны (224–255).
- `last-error.txt` туннеля больше не содержит ANSI-цвета sing-box.
- PID фонового стартёра туннеля проверяется по имени процесса (powershell/pwsh): после перезагрузки чужой процесс, занявший PID, не будет убит как стартёр.
- Диагностика вызывает `curl.exe` напрямую, без сборки командной строки через `cmd.exe /c`.
- Параметры с кавычками или переводами строк (`-ZapretRoot`, `-TunnelConfig` и др.) отклоняются до перезапуска с правами администратора: раньше они могли исказить командную строку UAC.

### Тесты

- Pester-тесты чистых функций (24 шт.): сравнение версий, base64, разбор ссылок, bogon-адреса, кодировка hosts, списки (в т. ч. чтение ANSI/UTF-8/UTF-16), закреплённые SHA-256. Запуск: `powershell -File tools\run-pester.ps1`; те же идут в CI на windows-latest.
- `Merge-ListFile` читает списки с автоопределением кодировки (BOM → UTF-8 → системная ANSI): файл, сохранённый в Блокноте как ANSI, больше не превращает кириллический комментарий в мусор и не мешает распознавать дубликаты строк.
- Новые `.ps1` (тесты, лоадер) сохранены как UTF-8 с BOM, добавлен `.gitattributes` (`*.ps1 text eol=crlf`) и BOM-гейт в CI: Windows PowerShell 5.1 без BOM читает файл как ANSI и не разбирает русские строки вообще.

### Linux

- **Один экземпляр за раз**: эксклюзивный `flock` на `/var/lock/zapret2win.lock` для меняющих действий, общий — для `status`/`check`/`tunnel-list`. Раньше одновременный запуск двух меню мог перемешать записи в `hosts`, `config` или `profiles.json`. Второй экземпляр завершается с кодом 3 и понятным сообщением.
- **Атомарная запись** (`mkstemp` + `fsync` + `os.replace`) для `hosts`, `config`, `profiles.json`, `last-error.txt`, списков и отчёта: падение питания или Ctrl-C больше не оставляет полузаписанный файл. Секреты создаются сразу с правами 0600 (не бывают мгновенно читаемыми всем), отчёт теперь тоже 0600 — в нём адреса серверов.
- **Кодировка вывода команд** указана явно (`utf-8`, `errors="replace"`): при `LC_ALL=C` разбор вывода с кириллицей больше не падает.
- **Загрузки** (релиз, sing-box, xray, подписки) идут с ретраями и потоково в `*.part` с последующей атомарной подменой — обрыв сети не оставляет битый файл.
- **`doh_update` разрешает домены параллельно** (пул из 8 потоков) с живым прогрессом; порядок записей в `hosts` детерминированный. Это самое ощутимое ускорение: десятки последовательных таймаутов превращаются в несколько секунд.
- **`report`**: отладочный журнал nfqws2 пишется в `/opt/zapret2` (не в `/tmp` с предсказуемым именем — иначе symlink-атака), а штатный режим nfqws2 восстанавливается в `finally` — даже при Ctrl-C система не останется без обхода.
- **`strip_marked_block`**: при потерянном end-маркере блок DoH в `hosts` больше не вырезает хвост файла до конца — системные записи ниже сохраняются.
- **`pgrep -f`** вызывается с анкором начала командной строки и `re.escape`: процессы-«соседи» (редактор, `grep`, `less` с этим путём в аргументах) больше не считаются запущенным nfqws2.
- **Диагностика корректна и на iptables-системах**: проверка остаточных правил ищет `NFQUEUE`/`zapret` и в `iptables-save`, а не только в nftables.
- **Очистка экрана** — ANSI-последовательностью, без `os.system("clear")` (нет зависимости от внешней команды и лишнего процесса).
- **Коды выхода**: ошибки туннельных действий (`tunnel-on`/`tunnel-test` без профиля или при остановленном туннеле) возвращают ненулевой код; предупреждения и ошибки пишутся в **stderr**, чтобы `report > file` не смешивал их с полезным выводом.
- **`update` при `--yes`** больше не подтверждает откат на более старую версию (или файл без маркера): для этого нужен явный `y` или `--force`. Синтаксис новой версии проверяется во временном файле до подмены, замена — `os.replace`.
