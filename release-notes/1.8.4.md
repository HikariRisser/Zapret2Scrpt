## Zapret2 Windows / Linux 1.8.4

### Как обновиться

- **Linux:** скачайте `zapret2-linux.sh` из вложений и замените им прежний файл (изменений для Linux нет — версия поднята для согласованности).
- **Windows:** скачайте **один** файл — `Zapret2Windows.cmd` или `Zapret2Windows.ps1` — и замените прежний. После обновления один раз выполните установку (пункт **[1]**) или включите автозапуск заново (пункт **[3]**) — задачи планировщика переключатся на защищённую копию скрипта.

### Безопасность

- **Задачи планировщика запускают защищённую копию скрипта** (`C:\Windows\System32\Zapret2Windows\`), а не файл из рабочей папки. Раньше задача от имени SYSTEM выполняла скрипт оттуда, куда его положил пользователь: любую программу пользователя это делало повышением привилегий. Копия синхронизируется при установке, при включении автозапуска и при обновлении скрипта (пункт **[9]**).
- **Скачивания сверяются с SHA-256**: релиз zapret2, sing-box и xray-core сравниваются с контрольными суммами официальных релизов, несовпадение останавливает установку. Версия xray-core закреплена (v26.11.9) вместо `releases/latest`.
- **Явные права на каталоги**: боевому каталогу и каталогу туннеля задаются ACL напрямую (`icacls`) — ключи профилей (`profiles.json`) больше не читаемы обычными пользователями. Пользователям остаётся только чтение боевого каталога.
- Установщик .NET Framework проверяется по подписи Microsoft (Authenticode).
- Служба WinDivert перерегистрируется, только если она указывает на каталоги проекта — чужая служба стороннего приложения не трогается.
- Обновление скрипта: новый файл проверяется синтаксисом ДО записи, файл подменяется атомарно (через временный файл), резервная копия сохраняется как раньше.

### Исправления

- `hosts` при обновлении DNS больше не перезаписывается принудительно в ASCII: файл с кириллическими комментариями сохраняется как есть (UTF-8), а не молча превращается в знаки вопроса.
- Устранена гонка при первой установке: если каталог релиза появился, пока шла загрузка, установка больше не удаляет его молча, а использует или останавливается с понятным сообщением.
- У больших загрузок (релиз, sing-box, xray) появился таймаут; отключён прогресс-бар `Invoke-WebRequest`, замедлявший загрузку в PS 5.1.
- Код выхода внешних программ при проверке конфигов sing-box/xray сбрасывается перед вызовом: отсутствие файла больше не выглядит как успех предыдущей команды.
- Проверка версии PowerShell требует именно 5.1 (раньше пропускала 5.0), pwsh 6/7 предупреждает о непроверенности.
