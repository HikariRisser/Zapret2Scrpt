## Zapret2 Windows / Linux 1.8.1

### Как обновиться

- **Linux:** скачайте `zapret2-linux.sh` из вложений, замените им прежний файл и перезапустите туннель.
- **Windows:** скачайте **один** файл — `Zapret2Windows.cmd` или `Zapret2Windows.ps1`, замените прежний и перезапустите туннель (выключить и снова включить в меню туннеля).

### Исправление: приложение Telegram

Telegram Desktop и другие официальные приложения Telegram зависали на «Соединение…». Приложение подключается к серверам Telegram по IP-адресам, без DNS и без имени сайта в TLS. Поэтому его трафик не попадал ни в туннель (туда шли только домены через FakeIP), ни в профили zapret.

Теперь подсети Telegram ([официальный список](https://core.telegram.org/resources/cidr.txt)) всегда направляются в туннель на обеих системах. Настраивать прокси в самом Telegram не нужно.

Для работы приложения Telegram туннель должен быть включён.
